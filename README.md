# evc-free

Equipos gratuitos de **EduVolt Designer**, cifrados.

Cada versión (release) es una tanda publicada de la biblioteca. Los archivos
`.evc` van cifrados y se usan solo desde la app: EduVolt Designer los baja y los
abre por su cuenta. No hace falta descargarlos a mano.

---

Free components for **EduVolt Designer**, encrypted. Each release is a
published batch of the library. The `.evc` files are encrypted and are used only
from the app, which downloads and opens them by itself.
